Super Duper Vanilla

Un shader conçu pour conserver l'esprit visuel de Minecraft tout en ajoutant une atmosphère plus travaillée avec les ombres, la lumière, les reflets et les effets environnementaux.

VERSION 1.3.8
MINECRAFT 1.21.8
LOADER Iris
TYPE Vanilla / Réaliste
🌅 Lumière améliorée 🌊 Reflets 🌑 Ombres 🌫️ Atmosphère 🌿 Végétation
TÉLÉCHARGER SUR MODRINTH CURSEFORGE
📥

Installation

Pour utiliser Super Duper Vanilla, nous recommandons d'utiliser Iris.

  1. Installez Iris pour Minecraft Java Edition 1.21.8.
  2. Lancez Minecraft avec le profil Iris.
  3. Ouvrez les paramètres vidéo puis le menu des shaders.
  4. Ouvrez le dossier des shaders.
  5. Placez le fichier .zip de Super Duper Vanilla dans :
.minecraft/shaderpacks

⚠️ Les shaders sont recommandés mais ne sont pas nécessaires pour jouer à MaxPela.
