Prêt à rejoindre MaxPela ?

Quelques étapes pour placer les mods au bon endroit.

01

Installe Fabric

Choisis le profil Fabric correspondant à Minecraft 26.3.

02

Décompresse le ZIP

Extrais les fichiers JAR de l'archive téléchargée.

03

Ouvre le dossier mods

Depuis le launcher, ouvre le dossier du jeu. Crée mods s'il n'existe pas.

04

Lance le profil Fabric

Place tous les JAR dans le dossier et lance le profil Fabric 26.3.
